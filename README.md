### How I work

- I talk directly with the people who use what I build, and I start from how they actually work.
- I ship in small pieces and check each one before anyone else sees it.
- When something breaks in production, I find the root cause before I touch anything.
- I audit my own systems with a review protocol I wrote, packaged as a Claude Code skill.
